## Other project in this repo

`mining-ops-assistant/` is an unrelated project: a working demo of the *AI
Operations Assistant for Mining Companies* pilot proposal (automated shift
reports for mine supervisors/managers). See its own README for setup and a
demo script.

`gold-trading-bot/` is another unrelated project: an automated gold
(XAU/USD) trading bot with entry/exit signal generation, risk-based
position sizing, a paper-trading simulator (default) plus a MetaTrader 5
adapter for going live later, and push notifications to your phone on
every trade. See its own README for setup, backtesting, and the risk
disclaimer.
